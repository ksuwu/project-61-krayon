# GameZone - 20 Games in One Place

A responsive, no-build browser arcade made with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in a browser, or serve this folder with any static file server. No account, install, or API key is required.

Game scores and sound preference are stored locally in the browser. Internet access is used only for the hosted font and hero photograph; the games themselves run in the browser.
